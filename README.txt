COSMICKON COMIC-STYLE WEBSITE

Open this folder in VS Code and run index.html with Live Server.
This version uses five screen-sized pages. Use the top navigation or PREV/NEXT controls;
it is designed not to scroll vertically.

Add event links in script.js by replacing the PASTE_... placeholders.
Add WhatsApp QR images to the images folder, then set the three qrs paths in script.js.

Publish with GitHub Pages:
1. Create a public repository named cosmickon.
2. Upload index.html, style.css, script.js and images.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
